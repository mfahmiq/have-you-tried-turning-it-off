# Have You Tried Turning It Off?

The one funny line a hopeless tech support agent gives a desperate customer:

> I hear the deadline in your voice — have you tried turning it off and on again? It's the only fix on my list that doesn't need a ticket, a manager, or a miracle.

161 characters. The opening hears the customer's deadline in their voice, so the desperation is felt rather than explained; the middle is the oldest line in tech support, said dead straight; the punchline confesses the agent's whole toolbox is one item long — and everything else on his list is a ticket, a manager, or a miracle. The customer is never the butt of it; the support system is.

## How to run

```sh
python3 main.py
```

This writes the line verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it to stdout. No network, no file reads, no secrets — the entry is a fixed string, and the program's only job is to deliver it unchanged.
